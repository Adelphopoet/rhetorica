# UC-RH-7: Настроить агента и skills

## Purpose

Зафиксировать основной вариант использования и его наблюдаемый результат.

## Requirements

### Requirement: UC-RH-7 — Настроить агента и skills

<a id="uc-rh-7"></a>
Система SHALL позволять администратору собрать профиль агента из явных instructions, skills и allowlists.

**Основной актор:** администратор workspace.

**Цель:** опубликовать специализированного агента с понятными и проверяемыми границами доступа.

#### Scenario: Основной успешный сценарий

- **WHEN** администратор создаёт skill, назначает разрешённые коннекторы и публикует валидный профиль
- **THEN** агент появляется в каталоге и каждый его ход использует только закреплённый runtime snapshot
