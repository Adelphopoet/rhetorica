# UC-RH-11 — Общаться с выбранным агентом через MCP

## Purpose

Зафиксировать пользовательский путь выбора workspace-агента и продолжения одной беседы с ним через внешний MCP-клиент.

## Requirements

### Requirement: UC-RH-11 — Общаться с выбранным агентом через MCP

<a id="uc-rh-11"></a>
Система SHALL поддерживать путь от обнаружения доступного агента до многоходового MCP-диалога с сохранением его политики.

**Use Cases:** UC-RH-11

**Основной актор:** пользователь Rhetorica во внешнем MCP-клиенте.

**Цель:** выбрать подходящего workspace-агента и продолжать с ним контекстный диалог без повторной настройки каждого turn.

#### Scenario: Основной успешный сценарий

- **WHEN** пользователь получает каталог агентов через MCP, выбирает агента, задаёт первый вопрос и отправляет follow-up с возвращённым `conversation_id`
- **THEN** система отвечает на оба вопроса с настройками выбранного агента и возвращает один и тот же `agent_id`
