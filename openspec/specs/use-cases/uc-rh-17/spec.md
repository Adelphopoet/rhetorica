# UC-RH-17 — Запустить разработку из web-чата

## Purpose

Дать аналитику управляемый путь запуска разработки из web-чата без ожидания фоновой работы в HTTP-запросе и без передачи агенту дополнительных прав.

## Requirements

### Requirement: UC-RH-17 — Запустить разработку из веб-чата

<a id="uc-rh-17"></a>
Система SHALL выполнять разрешённое задание разработки из веб-чата до проверяемого результата со ссылкой на Draft MR.

**Основной актор:** аналитик.

**Цель:** Получить изменение dbt-проекта с проверками и Draft MR.

**Основной сценарий:**

1. Аналитик включает coding рядом с выбором основного агента и задаёт изменение net_revenue в обычном веб-чате.
2. Система определяет доступные repo, target, environment и специалистов; при неоднозначности уточняет выбор.
3. Основной агент обсуждает вопрос и показывает план с поручениями developer и QA и критериями проверки.
4. Аналитик подтверждает актуальный план кнопкой в чате и видит run ID; developer готовит candidate.
5. QA проверяет неизменяемый candidate; developer исправляет замечания в оставшемся бюджете.
6. При успешных обязательных проверках и действующих grants система создаёт Draft MR.
7. Аналитик получает diff, QA-report, ограничения проверки и URL MR.

#### Scenario: Запустить разработку из веб-чата

- **WHEN** аналитик обсуждает и подтверждает в веб-чате план добавления поля net_revenue в разрешённый dbt-проект
- **THEN** система запускает developer и QA с настроенными правами и показывает результат со ссылкой на Draft MR

#### Scenario: Analyst запускает разработку

- **WHEN** analyst выбирает доступные repo, target, environment, developer и QA в web-чате и подтверждает задание
- **THEN** система возвращает run ID, выполняет developer и QA в сохранённых границах и показывает candidate, QA-report и доступный результат публикации
