# UC-RH-1: Получить аналитический ответ

## Purpose

Зафиксировать основной вариант использования и его наблюдаемый результат.

## Requirements

### Requirement: UC-RH-1 — Получить аналитический ответ

<a id="uc-rh-1"></a>
Система SHALL поддерживать полный путь от бизнес-вопроса до проверяемого ответа.

**Основной актор:** аналитик.

**Цель:** получить обоснованный ответ по данным без скрытия SQL и источников.

#### Scenario: Основной успешный сценарий

- **WHEN** аналитик выбирает агента, задаёт вопрос с периодом и показателем, а разрешённые источники доступны
- **THEN** система находит семантический контекст, проверяет и выполняет SQL и показывает ответ с evidence
