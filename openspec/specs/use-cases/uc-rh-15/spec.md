# UC-RH-15 Specification

## Purpose

Зафиксировать путь администратора от выбора локальной учётной записи до проверки применённого индивидуального лимита API-запросов.

## Requirements

### Requirement: UC-RH-15 — Ограничить API-запросы локальной учётной записи

<a id="uc-rh-15"></a>
Система SHALL поддерживать административный путь настройки индивидуального часового лимита локальной учётной записи и наблюдения его применения без изменения поведения остальных пользователей.

**Основной актор:** администратор workspace.

**Цель:** ограничить выбранную локальную учётную запись двадцатью API-запросами за скользящий час.

#### Scenario: Администратор настраивает лимит одной учётной записи

- **WHEN** администратор открывает раздел локальных пользователей, включает для выбранной учётной записи лимит 20 запросов в час и сохраняет настройку
- **THEN** список показывает `20 запросов / час`, первые двадцать учитываемых запросов этой учётной записи выполняются, следующий получает `429`, а пользователи без индивидуальной политики продолжают работу без этого ограничения
