# UC-RH-16 — Открыть полезные инструкции

## Purpose
Зафиксировать путь аналитика от открытия панели «Полезные инструкции» до перехода в гайд по описанию метрик.

## Requirements

### Requirement: UC-RH-16 — Открыть полезные инструкции

<a id="uc-rh-16"></a>
Система SHALL открывать по действию аналитика панель «Полезные инструкции» со списком ссылок на гайды и открывать выбранный гайд в новой вкладке браузера.

**Use Cases:** UC-RH-16

**Основной актор:** аналитик.

**Цель:** быстро открыть нужную инструкцию из рабочего чата, не покидая текущий контекст анализа.

#### Scenario: Аналитик открывает инструкцию

- **WHEN** аналитик открывает панель «Полезные инструкции» с приветственного экрана или из панели инструментов чата и нажимает ссылку «Заполнение метрик в OpenMetadata»
- **THEN** руководство по описанию метрик открывается в новой вкладке браузера, а чат сохраняет текущее состояние
