# UC-RH-13 — Использовать коннекторы workspace из внешнего MCP-клиента

## Purpose

Зафиксировать путь пользователя, который из собственного MCP-клиента обращается к коннекторам workspace Rhetorica без установки и настройки этих коннекторов у себя.

## Requirements

### Requirement: UC-RH-13 — Использовать коннекторы workspace из внешнего MCP-клиента

<a id="uc-rh-13"></a>
Система SHALL поддерживать путь от подключения внешнего MCP-клиента к Rhetorica до успешного вызова tool MCP-коннектора workspace без передачи credentials коннектора пользователю.

**Use Cases:** UC-RH-13

**Основной актор:** пользователь Rhetorica во внешнем MCP-клиенте.

**Цель:** получить через один токен Rhetorica доступ к метаданным, задачам и документации из подключённых к workspace MCP-коннекторов и к данным через `run_sql`, не устанавливая отдельные MCP-серверы и не храня их credentials.

#### Scenario: Основной успешный сценарий

- **WHEN** пользователь подключает внешний MCP-клиент к `/mcp` с токеном Rhetorica и задаёт вопрос, для ответа на который клиент ищет таблицу в OpenMetadata через tool коннектора и затем выполняет `run_sql`
- **THEN** клиент обнаруживает tools коннекторов в `tools/list`, успешно вызывает их через Rhetorica и получает ответ, не зная credentials коннекторов
