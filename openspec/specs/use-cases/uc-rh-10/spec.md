# UC-RH-10 — Подключить внешний MCP-клиент

## Purpose

Зафиксировать основной пользовательский путь подключения внешнего AI-клиента к персонально авторизованному MCP Rhetorica.

## Requirements

### Requirement: UC-RH-10 — Подключить внешний MCP-клиент

<a id="uc-rh-10"></a>
Система SHALL поддерживать путь от выпуска персонального токена до первого успешного аналитического вызова из внешнего MCP-клиента.

**Use Cases:** UC-RH-10

**Основной актор:** пользователь Rhetorica.

**Цель:** безопасно подключить OpenAI, Claude или другой совместимый MCP-клиент к своему workspace без передачи browser-session cookie.

#### Scenario: Основной успешный сценарий

- **WHEN** пользователь выпускает токен со scopes MCP, копирует показанные UI endpoint и Bearer token в совместимый клиент и инициирует подключение
- **THEN** клиент обнаруживает возможности Rhetorica и успешно выполняет разрешённый аналитический tool от имени пользователя
