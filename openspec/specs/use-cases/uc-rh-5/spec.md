# UC-RH-5: Запустить сохранённый сценарий

## Purpose

Описать создание и повторяемый запуск аналитической цепочки с правами инициатора.
## Requirements
### Requirement: UC-RH-5 — Запустить сохранённый сценарий

<a id="uc-rh-5"></a>
Система SHALL исполнять доступную версию аналитического сценария с переданными параметрами.

**Основной актор:** аналитик; администратор управляет общими определениями.

**Цель:** повторить проверяемый аналитический процесс с наблюдаемыми промежуточными результатами.

#### Scenario: Создание и запуск аналитической цепочки

- **WHEN** аналитик создаёт личный сценарий по шаблону SQL → Python → LLM, выбирает коннектор и агента, настраивает передачу полного SQL-файла через выбор выхода шага, проверяет черновик, публикует версию и запускает её с параметром месяца
- **THEN** система возвращает идентификатор запуска, показывает состояния и результаты шагов, запрашивает предусмотренное графом подтверждение и предоставляет итог после одобрения

#### Scenario: Запуск общего сценария

- **WHEN** аналитик выбирает опубликованный администратором общий сценарий и заполняет параметры
- **THEN** система выполняет выбранную версию с правами аналитика и предоставляет аналитику историю этого запуска

#### Scenario: Разработка dbt по шаблону

- **WHEN** аналитик выбирает шаблон dbt-разработки, существующие коннекторы и разрешённых специалистов и запускает опубликованную версию
- **THEN** узел coding_task возвращает run ID, QA-report и Draft MR без изменения DWH
