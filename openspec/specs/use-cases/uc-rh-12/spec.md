# UC-RH-12 — Подключить MCP-клиент через OAuth

## Purpose

Зафиксировать пользовательский путь подключения внешнего MCP-клиента через браузерную OAuth-авторизацию без копирования Personal Access Token.

## Requirements

### Requirement: UC-RH-12 — Подключить MCP-клиент через OAuth

<a id="uc-rh-12"></a>
Система SHALL поддерживать путь от ввода MCP URL во внешнем клиенте до первого разрешённого MCP-вызова после входа и согласия пользователя.

**Use Cases:** UC-RH-12

**Основной актор:** пользователь Rhetorica во внешнем MCP-клиенте.

**Цель:** безопасно подключить внешний клиент к своему workspace без ручного выпуска и передачи PAT.

#### Scenario: Основной успешный сценарий

- **WHEN** пользователь вводит MCP URL, проходит перенаправленный login, подтверждает scopes и возвращается во внешний клиент
- **THEN** клиент автоматически получает и обновляет ограниченный доступ и успешно выполняет разрешённый MCP tool от имени пользователя
