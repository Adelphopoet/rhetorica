# NFR-RH-007: Полнота инструкции по запросу в портал управления доступом

## Purpose

Зафиксировать измеримое ограничение качества соответствующей capability Rhetorica.

## Requirements

### Requirement: NFR-RH-007 — Полнота инструкции по запросу в портал управления доступом

<a id="nfr-rh-007"></a>
Система MUST выдавать инструкцию по запросу в портал управления доступом, содержащую название роли и ссылку на портал портал управления доступом (https://access.example.com/).

**Use Cases:** UC-RH-9

**Метрика:** доля инструкций, содержащих название роли и ссылку на портал управления доступом.

**Порог:** 100% инструкций.

**Условия измерения:** сценарии отсутствия доступа (пути А–В).

**Проверка:** unit-тесты формирования инструкций.

#### Scenario: Выдача инструкции

- **WHEN** система формирует инструкцию по запросу в портал управления доступом
- **THEN** инструкция содержит название роли и ссылку на портал управления доступом
