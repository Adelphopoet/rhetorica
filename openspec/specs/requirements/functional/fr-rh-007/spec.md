# FR-RH-007: Файловые артефакты

## Purpose

Зафиксировать наблюдаемое функциональное поведение соответствующей capability Rhetorica.

## Requirements

### Requirement: FR-RH-007 — Загрузка входного файла

<a id="fr-rh-007"></a>
Система SHALL принимать только разрешённые файловой policy форматы и связывать принятый артефакт с пользователем, workspace и аналитическим ходом.

**Use Cases:** UC-RH-4

#### Scenario: Корректный CSV приложен к вопросу

- **WHEN** аналитик загружает непустой CSV в пределах настроенных лимитов
- **THEN** система проверяет имя, MIME, сигнатуру, квоту и делает артефакт доступным разрешённому file tool

#### Scenario: Подмена типа файла

- **WHEN** расширение, заявленный MIME и сигнатура файла не соответствуют друг другу
- **THEN** система отклоняет файл с детерминированным кодом policy-ошибки

### Requirement: FR-RH-007.1 — Выгрузка результата

<a id="fr-rh-007-1"></a>
Система SHALL создавать скачиваемый артефакт результата без изменения исходного execution snapshot.

**Use Cases:** UC-RH-4

#### Scenario: Результат выгружен в XLSX

- **WHEN** пользователь запрашивает XLSX для успешно завершённого SQL execution
- **THEN** система создаёт отдельный неизменяемый файл и возвращает ссылку на него с provenance выполнения
