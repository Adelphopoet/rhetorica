# FR-RH-003: Прозрачность результата

## Purpose

Зафиксировать наблюдаемое функциональное поведение соответствующей capability Rhetorica.

## Requirements

### Requirement: FR-RH-003 — SQL и evidence в ответе

<a id="fr-rh-003"></a>
Система SHALL сохранять и показывать пользователю SQL, выбранный коннектор, статус выполнения, источники и предупреждения, относящиеся к аналитическому выводу.

**Use Cases:** UC-RH-1, UC-RH-2, UC-RH-3

#### Scenario: Ответ построен по выполненному запросу

- **WHEN** SQL завершён успешно и его результат использован в итоговом ответе
- **THEN** пользователь может проверить текст SQL, источник, статус и связанные предупреждения в рамках того же результата

#### Scenario: Выполнение завершилось ошибкой

- **WHEN** DWH возвращает ошибку выполнения
- **THEN** система отделяет ошибку от пустого результата и не представляет незавершённое выполнение как подтверждённый факт
