# FR-RH-002: Семантическое обоснование

## Purpose

Зафиксировать наблюдаемое функциональное поведение соответствующей capability Rhetorica.

## Requirements

### Requirement: FR-RH-002 — Поиск управляемого контекста

<a id="fr-rh-002"></a>
Система SHALL искать таблицы, поля и бизнес-контекст через разрешённые агенту metadata и documentation providers до формирования исполняемого SQL.

**Use Cases:** UC-RH-1, UC-RH-6

#### Scenario: Источник найден в каталоге

- **WHEN** вопрос содержит бизнес-термин, сопоставленный с объектами доступного каталога метаданных
- **THEN** система использует найденные управляемые объекты и отражает их происхождение в evidence ответа

#### Scenario: Несколько равноправных источников

- **WHEN** поиск возвращает несколько источников без достаточного сигнала для детерминированного выбора
- **THEN** система показывает пользователю варианты для уточнения и не выполняет SQL до выбора
