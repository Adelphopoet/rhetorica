# Формат ответа и отчёта

## В чате

```
## Ответ
<число, факт или вывод, одна-две строки>

## Интерпретация
<много или мало, тренд, аномалия, что не проверено>

## SQL
<финальный запрос>

## Источник
<schema.table, коннектор, период данных, дата свежести>
```

## Файл отчёта `reports/<slug>/<slug>.md`

```markdown
---
tags: [analytics, <домен>]
date: YYYY-MM-DD
source: <schema.table>
---

# <Тема исследования>

## Ответ
...

![[<slug>.png]]

## Интерпретация
...

## SQL
```sql
...
```

## Источник
...
```

`<slug>`: тема и период, kebab-case, например `orders-may-2026`. Картинки через `![[<slug>.png]]` без пути, Obsidian найдёт сам. Одни данные в одной форме: либо график, либо таблица.
