# Правила SQL через Rhetorica

Governance Rhetorica: только `SELECT`, авто-`LIMIT`, таймаут. Не-SELECT отклоняется как `NON_READ_ONLY`.

## Всегда

- Явный `LIMIT` под задачу: `LIMIT 1000` на разведке, `LIMIT 50` для агрегатов.
- Фильтр по колонке даты и партиции в `WHERE`; сначала короткий период, потом целевой.
- Перечислять колонки, `SELECT *` не писать.
- `countIf` / `sumIf` вместо подзапросов с `WHERE`, где это ClickHouse.
- Часовой пояс задавать явно (`toTimeZone(dt, 'Europe/Moscow')`), если колонка `DateTime`.
- Статусы, отмены, тест-заказы: спросить в `business-context.md`, потом у человека; не фильтровать молча.
- Один запрос = одна мысль. Сложное считать шагами, промежуточный результат показать.

## Ошибки

- Ошибка синтаксиса или таймаут → упростить запрос (короче период, меньше группировок) и повторить, ошибку показать человеку.
- Пустой результат → проверить фильтры на коротком периоде без условий, потом сужать.
- `connector_name` неверный → `list_connectors` и выбрать по описанию.
