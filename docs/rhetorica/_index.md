# Rhetorica

Rhetorica — self-hosted рабочее пространство для аналитики на естественном языке. Система связывает вопрос пользователя с управляемыми метаданными, показывает сгенерированный SQL, безопасно выполняет запрос и возвращает объяснимый результат с источниками и ограничениями.

> **Открыть продукт:** [перейти в Rhetorica](https://rhetorica.example.com)

## Кому сюда

- **Пользователю** — быстрый старт, правила хорошего аналитического запроса, результаты, файлы и устранение типовых проблем.
- **Администратору** — коннекторы, агенты и workspace skills.
- **Разработчику** — локальный запуск, устройство монорепозитория, API, тесты и CI.
- **Архитектору и аналитику** — архитектура, FR, NFR и UC.

## Принципы

1. SQL прозрачен: пользователь видит, что именно было выполнено.
2. Ответ основан на управляемой семантике и доступных источниках.
3. Выполнение отделено от рассуждения и проходит явные проверки безопасности.
4. Ответ содержит происхождение данных, предупреждения и статус выполнения.
5. Если данных для корректного ответа недостаточно, система уточняет вопрос или честно останавливается.
