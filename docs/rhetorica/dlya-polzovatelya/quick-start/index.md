# Быстрый старт

## 1. Войдите в систему

Откройте [Rhetorica](https://rhetorica.example.com). В зависимости от окружения используйте корпоративный вход или локальную учётную запись. Если вход не проходит, не перебирайте пароли — обратитесь к администратору workspace.

## 2. Выберите агента

Агент определяет доступные источники и инструменты. Выберите карточку, соответствующую вашей задаче. Избранных агентов можно отметить для быстрого доступа.

## 3. Задайте проверяемый вопрос

Пример:

> Покажи недельную динамику количества заказов за последние 8 полных недель по федеральным округам. Исключи отменённые заказы. Верни таблицу и линейный график, укажи использованные таблицы.

Хороший запрос содержит:

- показатель;
- период;
- группировку;
- фильтры и исключения;
- желаемый результат.

## 4. Проверьте ответ

Не ограничивайтесь текстовым выводом. Проверьте:

1. какой источник и коннектор выбраны;
2. какой SQL выполнен;
3. нет ли предупреждений или уточнений;
4. совпадают ли период, фильтры и единицы измерения с вопросом;
5. завершилось ли выполнение успешно.

## 5. Продолжите диалог

Контекст сохраняется внутри разговора. Можно уточнить: «оставь только ЦФО», «добавь сравнение с прошлым годом» или «выгрузи результат в XLSX». Для новой несвязанной задачи создайте новый разговор.
