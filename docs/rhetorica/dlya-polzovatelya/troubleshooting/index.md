# Решение проблем

## Система просит выбрать источник

Это нормальная защита от неоднозначности. Выберите вариант по описанию и полному имени. Если нужного источника нет, попросите администратора проверить scope агента и коннектор.

## SQL отклонён до выполнения

Проверьте, что запрос read-only и содержит один оператор. Для изменения данных используйте штатный процесс DWH, а не Rhetorica.

## Выполнение завершилось ошибкой

Сохраните идентификатор выполнения, текст ошибки, время и имя коннектора. Повторяйте запрос только после понимания причины: слепые повторы могут создать нагрузку на DWH.

## Ответ не содержит данных

Проверьте период, фильтры, выбранный источник и предупреждения. Нулевой результат и техническая ошибка — разные состояния; интерфейс должен показывать их отдельно.

## Не загружается файл

Проверьте формат, размер и содержимое. Переименование расширения не меняет реальный тип файла и будет обнаружено проверкой сигнатуры.

## Нужна помощь

Передайте администратору: URL окружения, время, пользователя, агента, conversation ID или execution ID, ожидаемый результат и фактическое сообщение. Секреты и токены не прикладывайте.
