# Для пользователя

Начните с [быстрого старта](quick-start/), затем разберите [как формулировать аналитический запрос](analytical-request/) и [как читать результаты](results-files/). Для подключения внешнего AI-клиента используйте [API и MCP-токены](api-mcp/).

Главное правило: пишите бизнес-вопрос, период, разрез и ожидаемую форму результата. Названия таблиц не обязательны — если их можно однозначно найти в доступном каталоге.
