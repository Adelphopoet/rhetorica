# Результаты, визуализации и файлы

## Из чего состоит результат

В зависимости от задачи ответ может содержать:

- текстовый вывод;
- выполненный SQL и выбранный коннектор;
- таблицу-превью;
- график;
- ссылки на источники и артефакты;
- предупреждения, ограничения и статус выполнения.

Большой результат хранится как отдельный snapshot; интерфейс показывает ограниченное превью. Выгрузка не должна подменяться копированием строк из чата.

## Входные файлы

Поддерживаются TXT, Markdown, CSV, TSV, JSON, Parquet, XLSX, DOCX, PPTX, PDF, PNG и JPEG. По умолчанию действуют ограничения:

- до 25 МБ на входной файл;
- до 5 файлов и 50 МБ суммарно за один ход;
- пустые файлы, макросы Office и несовпадающие MIME/signature отклоняются.

Лимиты могут отличаться в конкретном окружении. При ошибке размера уменьшите файл или согласуйте изменение политики с администратором.

## Безопасная проверка выгрузки

Перед передачей файла проверьте дату формирования, исходный SQL, число строк, единицы измерения и наличие предупреждений. Экспорт является снимком результата и сам по себе не обновляется.
