# Обзор продукта

Rhetorica помогает получить проверяемый аналитический ответ, не скрывая SQL и источники за интерфейсом чата.

## Основной цикл

1. Пользователь выбирает подходящего агента и задаёт вопрос.
2. Агент определяет доступные ему источники и инструменты.
3. Система ищет таблицы и бизнес-контекст в каталоге метаданных и документации.
4. Перед выполнением SQL проходит синтаксическую и семантическую проверку.
5. Запрос выполняется через настроенный DWH-коннектор.
6. Интерфейс показывает ответ, SQL, данные, визуализацию, источники и предупреждения.

## Возможности

- диалоговая аналитика с сохранением истории;
- управляемое выполнение read-only SQL;
- каталог специализированных агентов;
- подключение DWH, LLM, RAG, документации, GitLab, Airflow, Kubernetes, VictoriaMetrics и MCP, включая MCP-серверы Jira, Confluence и каталогов метаданных;
- загрузка входных файлов и выдача созданных артефактов;
- сохранённые сценарии повторяемого анализа;
- обратная связь и исправление неудачного ответа;
- административный контур для коннекторов, агентов, skills и пользователей.

Rhetorica не подменяет владельцев данных и не делает неизвестную семантику «по догадке». Доступность функций зависит от политики выбранного агента и настроенных администратором коннекторов.
